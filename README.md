# my-popmetab
# ⚕️ 인구 대비 대사증후군 유병률 대시보드

행정안전부 주민등록 연령별 인구현황 + 2024년 건강검진통계연보 제7편(대사증후군)을
결합해서, **지역별·연령별 대사증후군 유병률**과 개별 위험요인(5가지)을
살펴보는 Streamlit 대시보드입니다.

## ⚠️ 꼭 읽어주세요 — 이 데이터가 의미하는 것

이 대시보드의 수치는 **"발생률"이 아니라 "유병률(수검자 기준)"**입니다.
2024년 국가건강검진을 받은 사람들 중, 검진 시점에 대사증후군 위험요인
5가지(복부비만·높은혈압·높은혈당·고중성지방혈증·낮은HDL콜레스테롤혈증) 중
**3개 이상을 가진 사람의 비율**이에요. 새로 생긴 환자 수가 아니라, 그
시점에 그 상태였던 사람의 비율이라는 점에 유의해주세요.

## 파일 구성

리포지토리 루트에 아래 7개 파일을 나란히 올려주세요.

```
your-repo/
├── main.py
├── requirements.txt
├── 202606_202606_연령별인구현황_월간.csv
├── metabolic_region_count.csv    # 시/도별 위험요인 보유개수별 (전처리됨)
├── metabolic_age_count.csv       # 연령별 위험요인 보유개수별 (전처리됨)
├── metabolic_region_factor.csv   # 시/도별 개별 위험요인 5가지 (전처리됨)
└── metabolic_age_factor.csv      # 연령별 개별 위험요인 5가지 (전처리됨)
```

## 데이터 검증

전국 수검자수(17,517,364명)와 대사증후군 인원(4,194,871명)이 원본 통계연보의
공식 수치와 정확히 일치하는 것을 확인했습니다.

## Streamlit Cloud 배포

1. https://share.streamlit.io 접속 → GitHub 계정으로 로그인
2. "New app" 클릭 → 리포지토리 / 브랜치 선택
3. Main file path에 `main.py` 입력 → Deploy

## 앱 구성

- **지역별 유병률**: 시/도별 대사증후군 유병률 막대그래프
- **연령별 유병률 추이**: 연령대별 유병률 + 주의군 비율 꺾은선 그래프
- **개별 위험요인 비교**: 5가지 위험요인을 지역별/연령별로 비교
- **고령화율과의 상관관계**: 산점도 + 피어슨 상관계수 (실제 계산 결과 약 0.65,
  중간~뚜렷한 양의 상관관계)

## 알아두면 좋은 한계점

- 지역 단위는 시/도(17개 광역단체) 기준입니다.
- '인구 대비 유병률' 지표는 근사치입니다. 검진 참여율이 낮은 지역은 이
  지표가 과소평가될 수 있어요.
- 통계연보의 '유병률(수검자 기준)' 비율은 원본에 이미 계산되어 있는 값을
  그대로 사용했습니다 (별도로 재계산하지 않음).
